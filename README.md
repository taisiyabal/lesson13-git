# Lesson 11: Maven, TestNG, Selenium

Учебный Maven-проект: класс Calculator с тестами TestNG
и BrowserDemo — простой сценарий Selenium WebDriver.

## Требования

- JDK 25
- Maven (или встроенный Maven в IntelliJ IDEA)
- Google Chrome

## Запуск

- Тесты: `mvn test`
- BrowserDemo: открыть `src/main/java/com/example/BrowserDemo.java`
  в IntelliJ IDEA и нажать зелёную кнопку Run рядом с `main`

## Что выводит BrowserDemo
- Текст заголовка после отправки формы
  - Подписи полей формы и пункты выпадающего списка
